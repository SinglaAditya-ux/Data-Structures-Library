## 📌 Project Scope
A console-based Data Structures Library built in C. It implements 4 major data structures — Linked List, Stack, Queue, and Binary Search Tree — with all their operations through an interactive menu-driven interface.

---

## ✅ Data Structures Implemented

### 1. 🔗 Linked List
- Insert at Beginning
- Insert at End
- Delete Element
- Search Element
- Display List

### 2. 📚 Stack (LIFO)
- Push
- Pop
- Peek (Top element)
- Display Stack

### 3. 🚶 Queue (FIFO)
- Enqueue
- Dequeue
- Display Queue

### 4. 🌳 Binary Search Tree
- Insert Node
- Inorder Traversal
- Preorder Traversal
- Postorder Traversal
- Search Element
